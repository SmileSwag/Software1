Gold Rush Grid is a free and open-source game using Python. It uses all the information and functions given in Software 1.

# How to start
1. You need to have Python installed.
2. install the coding application (eg. VS code)
3. clone the repository
4. Run the file to play the game.

# About 
- The goal of this project is to develop the program using python making small changes at a time while learning until you complete the whole project.

- The instructions and the main menu is provided in the project.

- The game is similar to the minesweeper (casual , exploration, puzzle)

# Step by step report while writing the code of the project

 I figured this game too late so I moved it into another folder and started writing again. So, I used the fundamental basics from project 1 to 4. 

 I inherited all the main menu, command menu and item format and the classed from the previous projects but removed the "add" and "remove" functions from project 4 in order to make the new game. I also changed the "room" class into "grid" style in order to use that in game. 

 The most challenging part is about writing the grid while hiding the main objectives (golds and mines) from the player side. I started writing with a list and substituting it after 1 move make it so hard. So, I changed it into looping function while saving the objective information in the backend.

 For the player module , the game saves the main informations with the player informations

 In the main program, everything from the previous project such as name , age , command menu can be seen. In addition, I added the instruction tab about the game that I created.

 I fixed few bugs such as text files missing due to incorrect directory, loading the save files on the last day of the class of the semester.
